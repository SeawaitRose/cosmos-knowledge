Public Guide

这套知识库如何运转

你和 Codex 的对话负责产生高质量知识，skill 负责深度追问和标准化，Markdown 负责阅读， graph.json 负责关系，网站负责管理、展示和自动化。

1. 从对话到知识

你输入读书感悟、复盘、牢骚、想法或决策。skill 先识别场景，再温和但锋利地追问，最后只沉淀高价值内容。

2. 标准知识包

每次入库先生成 Knowledge Package JSON，里面同时包含 Markdown 文档和图谱补丁。这是对话、网站和别人导入内容之间的统一标准。

3. 自动合并

合并脚本会校验知识包，写入 knowledge/books/、knowledge/cards/、knowledge/imports/，并更新 graph.json。

4. 图谱数据

knowledge/data/graph.json 存储节点和关系。网站根据它生成星体、轨道、任务和健康检查。

5. 外部上传

别人也可以用同一个 skill 生成 Knowledge Package JSON。上传到网站后先预检，确认无误再交给 Codex 合并。

6. 维护循环

每次入库后运行图谱校验、维护索引和健康检查，再打开知识星球观察结构是否更清晰。
